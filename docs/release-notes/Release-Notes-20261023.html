Minor changes

Storages and repositories by name

#313

On a target of another system, Browse is available once you have chosen the instance (or, for a shared system, the connection) to look with, instead of failing with a message about a missing connection. Choosing an object storage or a document repository now shows a list of their names with a filter box above it: type part of a name to narrow it, and click one to choose it. The field then shows the name, with the storage's project, and its id in brackets, for example CMC_Integration (dp-cmc) [5a026f29-…]; a saved target shows the same when you open it. An optional repository can be cleared. The browse window has a single Cancel button.
