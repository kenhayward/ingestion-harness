Minor changes

Storages and repositories by name

#313, #314

On a target of another system, Browse is available once you have chosen the instance (or, for a shared system, the connection) to look with, instead of failing with a message about a missing connection. Choosing an object storage or a document repository now shows a list of their names with a filter box above it: type part of a name to narrow it, and click one to choose it. Object storages are listed under their projects, and the filter matches storage names only. The field then shows the name, with the storage's project, and its id in brackets, for example CMC_Integration (dp-cmc) [5a026f29-…]; a saved target shows the same when you open it. An optional repository can be cleared. The browse window has a single Cancel button.

Manage connections in the account menu

#314

The menu under your name has Manage connections, for everyone: it opens the connections window where you add the logins CT Studio publishes with as you (your 3DEXPERIENCE login, for example), without going through Profile or Administration.

Decomposed documents can be delivered to a target

#315, #PR

Phase 1 (#315, merged) decomposes a Word document into its sections, tables, images and equations, checks that nothing was lost or changed in the process (a fidelity check), and comes with a command-line tool to run it. This PR (phase 2) lets a decomposed document be delivered to a target that supports it: the delivery contract moves to version 2, and a structured-authoring target receives the document as separate parts instead of a file. Targets that only take files and data are unchanged, and a decomposed document is refused for them rather than sent.

Running the same document again is recognised: if it was already delivered, nothing is created twice, and an updated version replaces the earlier one in the same place. A document that someone has edited in the target is never overwritten. The delivery stops and asks for a decision, naming the parts that changed there. CT Studio also keeps a register of what was delivered where, so a re-run knows which document it is updating.
