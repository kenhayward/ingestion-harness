Minor changes

Decomposed documents can be delivered to a target

#328

A decomposed Word document can now be delivered to a target that supports it: the delivery contract moves to version 2, and a structured-authoring target receives the document as separate parts instead of a file. Targets that only take files and data are unchanged, and a decomposed document is refused for them rather than sent.

Running the same document again is recognised: if it was already delivered, nothing is created twice, and an updated version replaces the earlier one in the same place. A document that someone has edited in the target is never overwritten. The delivery stops and asks for a decision, naming the parts that changed there. CT Studio keeps a register of what was delivered where, so a re-run knows which document it is updating.
