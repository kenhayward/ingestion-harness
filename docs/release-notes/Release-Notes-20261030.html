Minor changes

A document's time leaves out its waits

#371

The time beside each document in a batch was everything from when CT Studio picked it up to when it was delivered. In a large batch, or one from a watched folder, much of that is waiting for the target to take it, so a quick document could show a long time. Now the time is the work alone, converting the document and delivering it, so you can see which documents take long and which are quick.

  • The wait for the target's turn, and the wait for a held PDF's review, are left out. The document's panel shows them separately as Waited, for example 5 min, not counted.
  • While a document waits its time stops, shown as 30 s so far, and it carries on once its delivery starts.
  • Documents converted before this change have no waits recorded, so their times stay.

Fixes

Word tables with a header merged over an empty row

#372

A Word document (TPR-003408) was refused on delivery with row 2 has no cells. Its Table 7 has a header row whose every cell is merged down over a second row, so that row holds nothing of its own: Word shows it only as extra height in the header. The empty row is now left out and the merged cells are one row shorter; the table reads the same, and the check against the source leaves the row out the same way. Re-run the document once this is deployed.

Word documents with an invisible shape

#373

A Word document (32P23 Process Characterization) failed with drawing … could not be rendered. Its Table 3 caption holds a tiny rectangle with no fill, no outline and an empty text box, the kind of leftover Word keeps after an edit. Rendered, it is a blank page, so there was no picture to keep and the document failed. A shape like this, which shows nothing (no fill, no line, no text, no picture and no alt text), is now left out, and the check against the source leaves it out the same way. A shape with any fill, line, text or alt text is still rendered as before. Re-run the document once this is deployed.

Hidden Word tables

#374

The same document's last section arrived with a large empty table that Word doesn't show. It is template guidance, a "Verification of Data" table for authors and verifiers, hidden from print: every row is marked hidden, and so is all of its text. Hidden text was already left out, but the table's rows were kept, so the target showed an empty grid of 103 rows (and an empty one-cell table after it). A table Word shows nothing of, every row hidden and everything in it hidden, is now left out, and the check against the source leaves it out the same way. A table with anything shown in it is kept as before. Re-run the document once this is deployed.
